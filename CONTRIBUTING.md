# Contributing to Tungsten

Development currently takes place in the private Myoon monorepo. This
public repository contains official release snapshots and tags, rather than
mirror internal development commits.

Feedback, bug reports, minimal reproductions, and feature ideas are welcome at
[contact@myoon.sk](mailto:contact@myoon.sk). Include the schema, Tungsten version,
expected behavior, and actual behavior. Remove application credentials and private
user data from examples.

External code contributions are not being accepted yet. Before opening that flow,
we will publish a CLA or equivalent contributor agreement and its acceptance
process. It must provide sufficient rights to offer contributed code under both
the AGPL and a commercial license. No such rights are assumed merely from sending
code or opening a pull request.

See [LICENSE](LICENSE) and [commercial licensing](COMMERCIAL-LICENSING.md).
